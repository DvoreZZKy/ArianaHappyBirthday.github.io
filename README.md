# 🎂 Сайт ко дню рождения Арианы

Персональный сайт-подарок, сделанный специально к 17-летию.  

## 📁 Структура проекта
- `main.html` — главная страница с поздравлением
- `about.html` — раздел «О тебе»
- `interactive.html` — интерактив: кнопка «Сюрприз» и таймер до 18-летия
- `atmosphere.html` — атмосфера: моменты, цитаты, секретная пасхалка
- `style.css` — стили
- `mainscript.js` — скрипты (анимации, таймер, сюрпризы)
- `Assets/imgs/` — изображения (цветы, иконки)

## 🚀 Как запустить
Открой ArianaHappyBirthday.github.io

## ✨ Особенности
- Плавные анимации появления текста.
- Таймер обратного отсчёта до 18-летия.
- Секретная пасхалка.
- Никаких фотографий — только текст, смыслы и эмоции.

## 🛠️ Технологии
- HTML5
- CSS3 (анимации, градиенты)
- JavaScript (таймер, рандомные комплименты, модальное окно)
- Canvas (фоновая анимация частиц)

## 📝 Примечание
Проект создан как личный подарок. Некоторые тексты и факты заполнены вручную и являются субъективными.
